# GeoMata

GeoMata is a tool for analysing Earth observation data globally using remote sensing data.

## Overview

GeoMata is intended to help users explore, process, and understand information collected by Earth observation satellites and other remote sensing systems. It can support analysis across different regions, time periods, and environmental or geographic indicators.

## Planned capabilities

- Work with global remote sensing datasets
- Explore changes across locations and time
- Analyse environmental and geographic patterns
- Produce maps, summaries, and other useful visual outputs
- Support reproducible Earth observation workflows

## Status

GeoMata is under development. More details about installation, usage, supported data sources, and contributing will be added as the project evolves.
